# Protocolo-de-Transi-o
Já mandou currículo pra área nova e sentiu que "não conversa" com a vaga? O problema não é sua experiência, é que ninguém te ensinou a traduzir ela.  O Protocolo de Transição é o método pra reposicionar currículo e LinkedIn e conseguir chamadas de entrevista, mesmo sem experiência formal na nova área.
